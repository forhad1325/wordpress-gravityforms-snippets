# LeadDocket + Gravity Forms Integration

Sends Gravity Forms submission data to the LeadDocket CRM API after form submission.

## Usage

1. Paste code into your theme's `functions.php` or a custom plugin.
2. Replace `YOUR_DOMAIN` and `YOUR_FORM_ID` with your LeadDocket endpoint.
3. Update the Gravity Forms form ID (`4`) and field IDs to match your form.

## Requirements

- Gravity Forms
